# Historical archive — not the active runtime

Archived on 2026-09-15. The repository root contains the continuous-market MVP;
use its `README.md`, `IMPLEMENTATION_MVP_2026-09-13.md`, and `configs/mvp.yaml`.
Nothing in this directory is imported by that runtime or collected by its
default test suite. Historical instructions here are not current instructions.

## auction/

The complete tracked source tree from the last pre-migration commit,
`0f3243f5824da946bb38d4e5b18dec169e44b94a` (`stale`), is preserved at the same
relative paths. This includes the old versions of modules that have since been
rewritten for the MVP, old launch script and requirements, all four auction
YAMLs, implementation/specification/output documents, and the old tests
(including tests removed during migration). The snapshot's older MVP guide is
historical too; the authoritative guide remains at the repository root.

Files that still existed only for the auction version were moved here; shared
files already rewritten for the MVP were recovered from Git without changing
their active working copies. No commit or reset was performed.

Also moved intact from the working directory:

- `data/`: old listener logs and `market.db`, including its WAL/SHM sidecars.
- `runs/`: `2026-09-02-1417`, `2026-09-02-2040`, `2026-09-04-trial`, their
  configurations/databases/logs/W&B outputs, plus `live.out` and the superseded
  `instruct-0911.txt` proposal. W&B symlinks retain their original targets; an
  existing absolute link to a user-level W&B cache is not a portable file copy.
- `prediction_markets/.env`: the old provider credential file. It remains
  gitignored and is never loaded by the MVP. Do not share it or use `git add -f`.

The archived data/runs remain gitignored, as before. Thus a Git clone alone
does **not** back up the local experiment data or credentials; preserve this
directory separately if you need those artifacts on another machine. No data
was discarded and SQLite files were not opened for migration or settlement.

This is a historical record, not a supported second runtime. Do not launch its
scripts with the current environment or point the MVP at its databases.

## generated-caches/

The previous pytest cache and mixed old/current Python bytecode caches were
moved here rather than deleted. They are gitignored and not needed to recover
source code. Current caches may be regenerated by ordinary Python/test runs.

The existing `.venv` and current `data/huggingface/` tokenizer cache remain at
the root for the MVP. MVP run directories belong under root `runs/`, including
the new `20260916T065126Z-6d7bece4` directory that appeared during this archive
operation and was retained there. Archived auction runs are not resumed.
